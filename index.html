qag-data

The shared research-data backend for R&R Droids sites. Versioned JSON & CSV, CORS *, free for research use. Every dataset below is fetched live by at least one production site.

● LIVE CORS-OPEN API

Consuming sites

fetch('https://qag-data.vercel.app/carbon-capture/vectors.json')
